# Write a clear report

Use this procedure when the user requests a report or formal summary.

1. Clarify the audience and purpose if they are missing.
2. Use only facts supplied by the user or approved knowledge and tools. Identify missing evidence instead of inventing figures.
3. Organize the response into **Findings**, **Risks**, and **Next steps**.
4. Keep actions specific, identify assumptions and preserve required citations.
5. Follow the agent's response-language and access policies.

If `references/outline.md` is included, use its outline. Otherwise use the headings above. This skill requires no executable scripts.
