# Console UI conventions

Agent Connex keeps common actions visible and technical details available on demand. Existing configuration, permissions, revision checks and runtime behavior remain authoritative.

## Page structure

Use a compact page title and one sentence of context. A panel heading identifies the current resource; avoid repeated slogans or explanatory paragraphs. Use a single primary action and secondary actions with consistent spacing. Fields and buttons must have room inside their borders and wrap on small screens.

Shared styles cover Agents, Workflows, Knowledge, Connectors, Skills, Models, Tools, Quality, Operations, Channels and Secrets. Check both themes at mobile, tablet and desktop widths, including long names, validation messages and open overlays. Do not hide required warnings behind help.

## Help and advanced settings

Use `HelpTooltip` for brief field explanations. It opens on hover, keyboard focus or tap, dismisses on Escape/outside interaction and stays within the viewport. Tooltips render outside clipping panels, but inside the active dialog when necessary. Use `SetupGuide` or a details disclosure for longer instructions or links. Keep errors and missing setup instructions visible.

Technical controls remain grouped with their feature or in Advanced. Skill instruction bodies, JSON, version history, debug output and reference files should open only when requested.

## Guided connector setup

The connector editor shows Destination, Account and Source & sync one at a time. Continue checks the destination name/knowledge base and the selected account. Back and step navigation retain edits. Review the source, optionally expand Sync limits & schedule, then save. Existing manual credentials, OAuth, source browsers and synchronization settings remain available.

## Quality datasets

Use Test questions to edit questions, expected behavior and optional expected answers. Large datasets show five questions per page. Adding or editing questions preserves advanced assertions and metadata. Advanced JSON / import supports the complete existing example format; malformed imports stay editable with a visible error.

## Workflow canvas and chat

Choose the current workflow using the compact selector; switching a dirty draft asks before discarding edits. The canvas retains its node palette, inspector, expanded mode and test panel. Playground prioritizes messages and the composer; voice and Debug remain optional. Published deployments retain their hosted links and copyable embedding snippets.

## Regression checks

Browser coverage includes page widths/themes, shared panel gutters, connector steps, advanced JSON preservation, tooltip hover/focus/Escape, workflow execution and expanded canvas, plus Skills and Agent configuration flows. Screenshot artifacts are generated by the UI polish browser suite for review.
